# Call Center skills

Use these skills for Call Center customization only. Install them alongside the [shared skills](../shared/README.md). See [Setting up the skills](../README.md#setting-up-the-skills).

| Skill name | Description | Example prompt |
| --- | --- | --- |
| [cc-call-apis](cc-call-apis/SKILL.md) | Use BucCommOmsMashupService to call Call Center mashups from custom code, including paginated lists, and show success or error notifications. | "Call a mashup to load the customer's open returns in pages of 10, and show an error notification if it fails." |
| [cc-configure-address-formats](cc-configure-address-formats/SKILL.md) | Set per-country address display order, mandatory fields, contact fields, and numeric fields for Call Center address pages with buc-address-field-config.json. | "For Canadian addresses, show postal code before city and make the province mandatory." |
| [cc-configure-home-portlets](cc-configure-home-portlets/SKILL.md) | Reorder, resize, or hide Call Center home page portlets (order, customer, return search, alerts) through cc-home-custom-widget-config.json, without writing code. | "Put the customer search portlet first on the home page and hide the alerts portlet." |
| [cc-customize-common-components](cc-customize-common-components/SKILL.md) | Change a component in the shared @buc/cc-components library (customer create, address edit, payment, store search, home portlets, and more), link the rebuilt library into the Call Center modules that use it, and package it with those routes. | "Change the store search component in `@buc/cc-components` to sort stores by distance, and link it into the order module." |
| [cc-customize-customer-create-fields](cc-customize-customer-create-fields/SKILL.md) | Add optional or mandatory fields to the Call Center customer creation forms, which come from the @buc/cc-components library. | "Add a mandatory 'Loyalty ID' field to the consumer customer creation form." |
| [cc-customize-existing-action](cc-customize-existing-action/SKILL.md) | Replace the behavior or modal of an existing Call Center action (for example Adjust pricing, Add note, Manage holds) by re-registering the action name with CUSTOM_ACTIONS or CUSTOM_FEATURE_ACTIONS and a copied modal component. | "Make the Add note action require a reason code before the note can be saved." |
| [cc-customize-global-search](cc-customize-global-search/SKILL.md) | Customize the Call Center global search bar and home page search, including matched fields, query types, type-ahead, URL hiding, and corresponding placeholder text. | "Let the global search bar match customer phone numbers with 'starts with', and update the placeholder text." |
| [cc-customize-home-portlet-code](cc-customize-home-portlet-code/SKILL.md) | Override an IBM home page portlet's code or add a new portlet in Call Center using the custom-home-portlet app in call-center-custom, linked to the cc-components library, then run and build it. | "Add a new home page portlet that lists today's orders on hold." |
| [cc-customize-payment-methods](cc-customize-payment-methods/SKILL.md) | Build the capture UI for Call Center payment types (credit card, debit card, SVC, or your own) as an iframe app in call-center-custom, wire it with paymentTypes in app-bootstrap-config.json, and implement the postMessage contract. | "Build a capture screen for our 'Store credit' payment type and wire it into Call Center." |
| [cc-customize-search-fields](cc-customize-search-fields/SKILL.md) | Add, hide, or override search fields on the Call Center order, return, customer, alert, and enhanced order search pages with search_fields.json, including fetched drop-downs, operators, filter groups, and facets. | "Add an 'Order channel' drop-down to order search, filled from the OMS common codes, and hide the Carrier field." |
| [cc-customize-shared-component](cc-customize-shared-component/SKILL.md) | Change a component from a Call Center module's shared library (order-shared, return-shared, customer-shared, alert-shared) for one route using an [extn] attribute selector, or for every route by editing the shared library. | "Change the order header component from `order-shared`, but only on the order details route." |
| [cc-customize-styles](cc-customize-styles/SKILL.md) | Override Call Center styles globally with custom_styles.css for the shell (login, banner, navigation, global search) and the hub (home page and every module page). | "Change the top banner to our brand blue and use a larger font for page titles across Call Center." |
| [cc-extend-mashups](cc-extend-mashups/SKILL.md) | Get new data into the Call Center UI by extending the /icc mashup layer. Covers incremental, override, and new mashups, custom Java mashup classes, naming rules, and how to build and deploy them. Needed whenever a new column, field, or search attribute is blank. | "My new 'Customer PO' column on the order lines table is blank. Extend the mashup so it returns `CustomerPONo`." |
| [cc-navigation](cc-navigation/SKILL.md) | Make a custom Call Center route reachable - add its left-menu entry in features.json and register it with call-center-hub through routes.json and import-map.json, for local development and deployment. | "Add a 'Returns dashboard' menu item for my new custom route and register it with call-center-hub." |
