# Shared skills

These skills apply to both Order Hub and Call Center. Where the products differ, the skills provide the Call Center steps in a marked **Call Center** note. Install them together with either the [Order Hub skills](../orderhub/README.md) or the [Call Center skills](../call-center/README.md). See [Setting up the skills](../README.md#setting-up-the-skills).

| Skill name | Description | Example prompt |
| --- | --- | --- |
| [buc-add-content-via-extension-point](buc-add-content-via-extension-point/SKILL.md) | Add content to an existing Order Hub/Call Center page or modal through its extension points, keeping your code fully separate from IBM code so product updates don't need a merge. | "Show a shipment notice section at the bottom of the order details page, using the `order_details_od_bottom` extension point." |
| [buc-add-custom-action](buc-add-custom-action/SKILL.md) | Add a custom action to an existing Order Hub/Call Center page's Actions menu through buc-page-definitions.json, and handle it with an action service. | "Add a 'Notify customer' action to the order details Actions menu that calls our notification service." |
| [buc-add-custom-hotkeys](buc-add-custom-hotkeys/SKILL.md) | Add keyboard shortcuts to an Order Hub/Call Center page through the hotkeys section of buc-page-definitions.json, including CSS targeting and troubleshooting. | "Add a Shift+R shortcut on the Create Order page that clicks the Clear button." |
| [buc-add-custom-tab](buc-add-custom-tab/SKILL.md) | Add a custom tab to an existing Order Hub/Call Center details page through buc-page-definitions.json, without taking ownership of the page. | "Add a 'Fraud review' tab to the order details page that shows our fraud check results." |
| [buc-add-page-to-route](buc-add-page-to-route/SKILL.md) | Add a new Angular page and child route inside an existing Order Hub/Call Center route package (for example a page in order-search), with breadcrumbs and permission control. For a new route package with its own dev server port and deployment entry, use buc-add-route-package instead. | "Add a 'Hold review' page at path `hold-review` in the `order-search` route of `buc-app-order`. Only users with resource ID `CUSORD0004` can open it." |
| [buc-add-route-package](buc-add-route-package/SKILL.md) | Create a new route package in an existing Order Hub/Call Center monorepo (an IBM module like buc-app-order, or your own custom app), including the schematic scaffolding, dev server configuration, menu item, and deployment. | [buc-configure-editable-columns](buc-configure-editable-columns/SKILL.md) | Make columns in an existing Order Hub/Call Center table editable by registering an editable-fields service against the table configuration. | "Make the Line type column editable in the order lines table and save the change through `changeOrder`." |
| [buc-configure-generated-assets](buc-configure-generated-assets/SKILL.md) | Choose schema and translation output paths for BUC component schematics writing into src-custom. | "Which `--json-file-path` and `--translation-file-path` should I pass when generating a table in the `order-details` route?" |
| [buc-configure-table-export](buc-configure-table-export/SKILL.md) | Control the Order Hub/Call Center table data export feature - what users get from it, and how to turn it off globally or per table for data-governance reasons. | "Turn off data export on the order search results table only, and leave it on everywhere else." |
| [buc-create-new-app](buc-create-new-app/SKILL.md) | Create a new standalone custom Order Hub/Call Center application repository with the ng-new schematic, then run it locally inside Order Hub/Call Center. Use for capabilities that don't belong inside an IBM module. | "Create a standalone app called `custom-kpis` with two pages, and add both to the left menu." |
| [buc-customize-by-configuration](buc-customize-by-configuration/SKILL.md) | Change Order Hub/Call Center labels, table columns, table actions, and search fields by editing JSON only, with no code. Use this before considering a code-based approach. | "Rename the 'Error code' column on the exception search results table to 'Failure code', using configuration only." |
| [buc-customize-by-overrides](buc-customize-by-overrides/SKILL.md) | Take over an existing Order Hub/Call Center component, data service, or action by copying it into src-custom and editing it. | [buc-customize-field-details](buc-customize-field-details/SKILL.md) | Full reference for buc-field-details.json, covering how to add fields to details-page summary panels, bind them to API data, and make them editable. Use for order, shipment, inventory, exception, and alert detail pages. | "Add an editable 'Entry type' field to the order details summary panel." |
| [buc-customize-locales-i18n](buc-customize-locales-i18n/SKILL.md) | Add and test a custom language or locale in Order Hub/Call Center, covering the shell, each module, and the login page. | "Add Swedish as a selectable language for the shell and the order module, and tell me how to test it." |
| [buc-customize-login-page](buc-customize-login-page/SKILL.md) | Rebrand the Order Hub/Call Center login page through shell-ui assets, including the title and banner text, logo image, and shell-level CSS. Use for organization branding rather than page customization. | "Rebrand the login page for Acme: title 'Acme Fulfillment' and our logo `acme-logo.png`." |

Which library components should I use?" |

| [buc-generate-search-result](buc-generate-search-result/SKILL.md) | Generate an Order Hub/Call Center search results page and its table in one step with the search-result-component schematic. | "Generate a quick shipment results page with a table of shipment number, status, ship node, and expected ship date." |
| [buc-generate-summary-component](buc-generate-summary-component/SKILL.md) | Generate a field component or summary side panel using schematics, for displaying labeled record values (details, create, or search pages), including one mounted at an extension point. | "Show a read-only 'Order context' section with the enterprise code and document type at the bottom of the Create Order page." |
| [buc-generate-table-component](buc-generate-table-component/SKILL.md) | Generate an Order Hub/Call Center data table with the table-component schematic, then configure its columns and wire it to an API.
