# Order Hub skills

Use these skills for Order Hub customization only. Install them alongside the [shared skills](../shared/README.md). See [Setting up the skills](../README.md#setting-up-the-skills).

| Skill name | Description | Example prompt |
| --- | --- | --- |
| [buc-call-apis](buc-call-apis/SKILL.md) | Call OMS APIs and service-domain REST APIs from custom Order Hub code, handle actions, and show success or error notifications. | "Write a data service that calls `getCommonCodeList` for the `NOTES_REASON` code type, and show an error notification if the call fails." |
| [buc-configure-getpage-templates](buc-configure-getpage-templates/SKILL.md) | Use getPage-templates.json to retrieve extra attributes from existing getPage API calls without writing code. Use when a custom column or summary field renders blank. | "My new Seal number column on the shipment table is blank. Add `SealNo` to the `getShipmentList` response." |
| [buc-create-features-json](buc-create-features-json/SKILL.md) | Add a custom app or page to the Order Hub left navigation menu using features.json, for both local development and deployment. | "Add a 'Custom triage' menu item under Exceptions that opens my `exception-triage` route, for local development and for deployment." |
| [buc-customize-navigation-routing](buc-customize-navigation-routing/SKILL.md) | Navigate from custom Order Hub code to another page, whether it's in the same Angular application or a different one. | "From my custom widget in `buc-app-workspace`, open the outbound order search with status 1100 already applied." |
| [buc-customize-search-fields](buc-customize-search-fields/SKILL.md) | Full reference for search_fields.json, covering field types, populating options from APIs, query operators, conditional display with showWhen, and targeting the right search API. | "Add a free-text 'Entry type' search field to order search, right after Order number, shown only when searching outbound orders by Status." |
| [buc-deploy-customization](buc-deploy-customization/SKILL.md) | Package, build, test, and deploy Order Hub customizations to an on-premises environment, as a customization image (containers) or a customization folder (traditional). | "My `create-order` customization works locally. Walk me through packaging it and deploying it as a customization image." |
| [buc-generate-dashboard](buc-generate-dashboard/SKILL.md) | Generate an Order Hub dashboard and its widget cards with the dashboard-component and dashboard-widget-component schematics, then define the card layout in dashboard-configs.json. | "Create an 'Order metrics' dashboard in `buc-app-order` with two cards: open orders and orders on hold." |
| [buc-generate-search-from-config](buc-generate-search-from-config/SKILL.md) | Generate a complete Order Hub search experience from one JSON configuration file, including the search page, results page, table, API service, and translations. | "Generate a work order search with criteria for work order number and status, plus a results table, from one config file." |
| [buc-hide-features](buc-hide-features/SKILL.md) | Hide built-in Order Hub features from the left navigation menu using a custom features.json entry. | "Hide the Promise and Fulfill menu item for all users." |
| [buc-merge-customization-updates](buc-merge-customization-updates/SKILL.md) | Merge existing Order Hub customizations onto a new code base after a fix pack or release, and audit which routes carry customization debt. | "We just installed a new fix pack. Find which routes we customized and help me merge our changes onto the new code." |
